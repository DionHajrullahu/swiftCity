# SwiftCity 🌍

SwiftCity is a city-discovery platform built to eliminate tourist traps and surface **verified, scannable local tips**.

Instead of long-form blogs, influencer content, or SEO spam, SwiftCity focuses on short, actionable insights from locals, insiders, and city experts.

---

## Live Demo
https://swiftcity.xyz

---

## Problem
Most travel content today is:
- Overwritten and hard to scan
- Unverified
- Optimized for clicks, not usefulness
- Dominated by influencers, not locals

SwiftCity is designed to be:
- Fast to scan
- Location-first
- Signal-based (verification, tiers, vibes)
- Built for real decision-making
